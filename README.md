# 几何画板

基于 Flask 的轻量几何绘图页面，包含点、线段、虚线段、数轴、常见三角形（含钝角三角形）与四边形、两种方向的椭圆和双曲线、四个方向的抛物线及直角坐标系。图形以 SVG 绘制，可在画布中添加、移动、缩放和删除，并可统一调整线条粗细。

## 启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

访问 [http://localhost:5005](http://localhost:5005)。

## 操作

- 点击左侧图形库，将图形添加到画布；选择“线段”或“虚线段”后，在画布上点击两点绘制两点之间的线段。
- 带坐标系按钮的缩略图可直接添加“图形 + 直角坐标系”组合；普通点击仅添加图形。
- 选中抛物线或双曲线后，可用画布上方的滑块调整开口宽窄和曲线延伸长度。双曲线的开口调整会保持焦点位置不变。
- 选择“直角坐标系”后，分别拖动 x 轴（上下）或 y 轴（左右）调整位置。
- 拖动图形以移动；选中图形后使用滚轮或工具栏 `+` / `−` 缩放。
- 使用“线条粗细”调整画布中所有图形的线宽。
- 选中图形后可删除；“清空画布”会移除全部图形。
